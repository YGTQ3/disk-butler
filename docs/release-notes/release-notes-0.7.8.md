# C盘管家 v0.7.8 更新说明

## 🔧 Bug 修复

- **Windows 沙盒「双 C 盘」修复**（issue #6）：沙盒的虚拟磁盘会挂载到 C 盘下的文件夹里，之前盘符列表会把它当成第二个「C 盘」显示出来；现在盘符列表只列真实的磁盘盘符，这类挂载到文件夹的虚拟卷不再出现
- **磁盘透视容量实时更新**：之前一键清理后切回磁盘透视页，可用容量还是旧数字；现在切回页面或点「重新扫描」都会自动拉取最新容量

## 🧹 清理规则扩充

- **新增**：NeatDM 下载缓存、美图秀秀缓存、搜狗 PDF 日志、万兴 PDFelement 日志、cargo 包管理器缓存
- **扩充**：WPS 缓存（补 WPS 图片）、游戏日志收录（补绝地求生 TslGame、永劫无间 NRC 等）

## 📚 透视知识库

- 新增美图、godot、cocos 等条目；火绒隔离区明确为保护项（只解释、绝不动杀毒软件的隔离区）

## 🩺 新工具

- **提权失败诊断脚本**（仓库 `tools/elevation-diagnose`）：如果你的高级功能被安全软件拦截报错，可自愿运行它收集诊断信息发给我们（普通权限即可运行，不修改系统、不联网）
