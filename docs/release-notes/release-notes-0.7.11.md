# v0.7.11 发布说明（2026-09-30）

## 背景
事故：GitHub [issue #12](https://github.com/YGTQ3/disk-butler/issues/12) 反馈「一键清理」页「高级·残留检查」把仍在使用的软件（Discord / 迅雷）误判为"已卸载"并列入可清理清单。复盘见 [docs/21-事故复盘-残留检查误报.html](../../docs/21-事故复盘-残留检查误报.html)（BUG 清单 8 条、根因不钉死、预期口径）。用户定案：**功能下架，确定可用前不再上架**。

## 本版本改动
- **下架「高级·残留检查」**：前端入口隐藏（`ORPHAN_FEATURE_ENABLED=false` + display:none）＋后端 `scan_orphan_dirs` / `clean_orphan_dirs` 命令不注册（两个 invoke_handler 分支均移除），commit `f030941`。函数体保留（`#[allow(dead_code)]`）以备修复验证后重新上架。
- **侧边栏显示完整版本号**：左下角由 `v0.7` 改为完整 `v0.7.11`（原待办排 0.8.0，应用户要求提前带入），同 commit。

## 验证
- cargo test 144 passed / 0 failed；tsc 0 错。
- CodeReview 子智能体两轮独立审查全 PASS（下架彻底、无误伤、版本一致、信任边界无回退）。
- 用户手动测试确认：残留检查入口消失、其他高级功能正常、侧边栏显示 v0.7.11。

## 影响面与处置
- 带此功能的旧版：v0.7.4 ~ v0.7.10（安装包下载合计 ≈9542）。旧版无法召回（零联网承诺），靠 Release 说明＋知乎公告引导升级与停用。
- 永久链 `DiskButler-Setup.exe` 已更新指向 v0.7.11（SHA256 `151EFAA5…04A8` 与版本包核对一致）。
- 删除不进回收站的危害已在公告中提示；误删用户补救口径见 docs/21。

## 不含
- PR#11（ntfs-reader 0.4.5→0.5.3 MFT 引擎升级）已合并入 main（`4f615bf`）但**不随本版发布**，留待 0.8.0——保持安全下架版纯粹，不混入引擎大改。
