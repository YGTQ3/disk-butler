# v0.8.0 发布说明（2026-09-30）

## 主题
「DISM 体验版」＋ 磁盘透视准确度大修。

## 本版本改动

### 1. 磁盘透视准确度大修（PR#11，感谢上游库作者 [@kikijiki](https://github.com/kikijiki)）
MFT 直读引擎依赖 `ntfs-reader` 从 0.4.5 升级到 0.5.3，删掉 831 行手写 MFT 底层代码、改用库 0.5 新 API（合并提交 `4f615bf`，squash）。修复了旧引擎一处**长期容量漏报**：
- **C 盘可用容量曾漏报约 16%**：旧引擎把 `$DATA` 排在扩展记录（`$ATTRIBUTE_LIST`）里的大文件算成 0 字节。真机 A/B 实测同一台机：旧 0.4.5 = 157.19 GB（−16%）、新 0.5.3 = 181.87 GB（−2.8%）、系统实际 = 187.08 GB。
- **硬链接计数修正**：从误把 DOS 8.3 短名别名当硬链接（53.3 万）修正为只数真硬链接（4.7 万）。
- **扫描更快**：全盘 MFT 扫描 29.88s → 4.48s。

### 2. DISM / WinSxS 清理体验（「DISM 体验版」主体）
「清理 Windows 更新旧版本备份 (WinSxS)」从"黑框干等、不知道死没死"改为"跑时可见、卡住会提示、文案诚实"：
- **已用时心跳**：分析 / 清理进行中实时显示「已用时 X 分 XX 秒」，不再只有一个静态估计干瞪眼。
- **诚实文案**：把「约 1~3 分钟」「约 5~20 分钟」这类硬承诺改为「通常…慢时更久」，数据诚实、不夸大。
- **卡住软阈值提示**：分析超 5 分钟、清理超 25 分钟时给出安心提示——分析是只读的、可放心重启重试；清理则明确劝「请勿关机、别强行中断」（途中断电有损坏组件存储的风险）。提示复用现有告警框样式，不另起视觉。
- （后端两道防呆——挂起更新预检 `update_pending` ＋ 退出码人话翻译 `dism_exit_hint`——已于 v0.7.10 上线，本版补齐前端体验。）

### 3. 诊断工具改进
`winsxs-diagnose` 只读分析硬超时 300 → 420 秒（7 分钟），慢机器不再被过早误判「卡死」；配套 README 判读口径同步。
