# C盘管家 v0.5.1

规则库大扩充 + 「在文件夹中打开」——删之前，先亲眼看看。

## ✨ 新功能

- **在文件夹中打开**（三处入口）：
  - 一键清理 → 查看详情 → 每条路径旁的 📂 按钮，删之前亲眼看看里面是什么；
  - 磁盘透视 → 点方块 → 详情卡「在文件夹中打开」按钮；
  - 磁盘透视 → **右键方块**直接打开资源管理器。

## 📚 规则库大扩充（来自真实机器样本 + 社区采集流水线）

- **新增 10 项清理规则**：剪映缓存、钉钉网页缓存、Playwright 测试内核、VS Code 缓存、uv 缓存、Adobe 媒体缓存 (Pr/Ae)、WPS 缓存、Android Studio 日志、Synology Drive 日志、AMD Radeon 缓存；
- **知识库新增 20+ 条识别规则**，重点：
  - **中文目录识别**：`微信`、`照片`、`备份`、`下载` 等中文命名目录正确识别为个人数据并标注"请勿删除"；
  - **保护规则**：WSL Linux 子系统磁盘、剪映草稿、网易邮箱大师邮件数据——这些"删了哭都来不及"的目录现在有明确警示；
  - 用户自行迁移的微信存储目录（如 `D:\wechat`）正确识别。

## 🤝 社区规则采集器

新增 `tools/collect-rules.ps1` + 双击启动器：帮 C盘管家认识你电脑上的小众软件。
不删除、不联网、报告可逐行审查（无文件名/无用户名）。用法见 [tools/README.md](https://github.com/YGTQ3/disk-butler/blob/main/tools/README.md)。

## 🛡 安全强化

- 规则扩充 SOP 新增强制准备步骤与"登录凭证令牌类目录"黑名单（拦截了外部评估中把微软登录令牌当缓存的危险误判）；
- 更新包清理文案补充边界提示：正在等待"重启以完成更新"的软件建议先重启再清理。
