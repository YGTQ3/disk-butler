# C盘管家 v0.7.10 更新说明

本版为纯修复版，专注两件事：磁盘透视的名字显示、高级清理（WinSxS）的报错体验。

## 🐛 Bug 修复

- **磁盘透视取名修复**：OneDrive 占位文件夹、符号链接（reparse 点）、大文件名等条目，之前在透视列表里可能显示空白或乱码名字，现在都能正确显示（MFT 取名改为自解析引擎，不再受第三方库对特殊记录跳过/中断的影响）
- **8.3 短名不再顶替真名**：只有 DOS 短名的条目之前会显示成 `XXXXX~1` 这类样子，现在优先采纳可读名字
- **升级后旧扫描缓存自动失效**：装新版后第一次扫描会重新解析，确保你看到的是修复后的正确名字，而不是旧缓存里的错名字

## 🛡 高级清理（WinSxS/DISM）加固

- **修复部分机器上「退出码 87（命令行参数无效）」报错**（issue #10）：DISM 改为绝对路径调用（不再受环境变量搜索影响），临时日志路径在个别用户名（含 `'` 等字符）下导致命令解析失败的问题也已修复
- **报错不再天书**：退出码 5 / 87 等常见错误直接显示人话原因（如"被系统环境拒绝，多为安全软件拦截"），并原样回显本次执行的命令，方便对照排查

## 🔧 新增维护工具（不影响日常使用）

- **WinSxS 一键诊断脚本**（`tools/winsxs-diagnose.bat`）：给"分析卡死/超时"场景用的只读诊断工具，自动采集系统状态、挂起更新、服务、DISM 交叉验证（含活体采样），生成一份报告文本。已在真实用户机器上实战验证有效（帮助定位了一次 1.5 小时分析卡死的原因）
